# Prior art, second pass

**2026-11-06.** This pass follows the [first pass](../prior-art-2026-10-31.md), which looked only at descriptions. This time we read the source and the commit history.

**Verdict: build fresh.** No existing tool has the author's own session answer reviewers' live questions, and that's Docent's core idea. The code we could legally reuse is the wrong shape. So we borrow ideas, not code.

## Ideas worth borrowing

1. **A checker loop.** The tour agent must pass a script before its tour counts. The script confirms every cited line exists in the diff, and that every changed file is either visited or skipped with a reason. ([pr-docent tour-prompt](https://github.com/thomas783/pr-docent/blob/main/scripts/tour-prompt.md), [diff.js](https://github.com/thomas783/pr-docent/blob/main/src/diff.js))
2. **The agent can write exactly one file.** `--allowedTools Read,Glob,Grep,Edit(<out>/tour.json),Bash(node check-tour…)` ([host](https://github.com/thomas783/pr-docent/blob/main/host/pr-docent-host.mjs))
3. **Tight headless calls:** `--tools=`, `--setting-sources local`, `--strict-mcp-config`, `--json-schema` reading back `structured_output`. Codex can be called the same way, which is a template for adapters. ([claudeCode](https://github.com/vivecuervo7/docent/blob/main/web/src/lib/models/claudeCode.server.ts), [codex](https://github.com/vivecuervo7/docent/blob/main/web/src/lib/models/codex.server.ts))
4. **Token tracking per job,** using `AsyncLocalStorage`, including cache reads and writes. ([usage](https://github.com/vivecuervo7/docent/blob/main/web/src/lib/models/usage.server.ts))
5. **Look up facts before touring.** "Report what's true, not whether the PR is right," with up to 25 facts, each citing file:line. ([codeContext](https://github.com/vivecuervo7/docent/blob/main/web/src/lib/features/panel/codeContext.server.ts))
6. **Stable hunk ids,** with model output checked against them. ([slices](https://github.com/vivecuervo7/docent/blob/main/web/src/lib/features/preparing/slices.server.ts))
7. **Every changed line has exactly one home.** Lines no stop covers show up under "Unexplained." ([pr-tour README](https://github.com/SjoerdP/pr-tour/blob/main/README.md))
8. **A skill on the author's side** as the way into the author's session. ([/tour skill](https://github.com/SjoerdP/pr-tour/blob/main/skill/tour/SKILL.md))
